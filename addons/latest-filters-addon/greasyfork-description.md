### F95UE Latest Filters Add-on

**Requires:** [F95Zone Ultimate Enhancer](https://greasyfork.org/scripts/546518-f95zone-ultimate-enhancer) (the core script)

Save useful Latest-page searches, clear individual filter groups, or let the
add-on choose a weighted random set of tags for you.

### Features

- **Saved Filters** — Save, search, update, apply, and delete reusable Latest filter combinations.
- **Filter Reset Controls** — Clear included tags, excluded tags, or one visible prefix group without disturbing category, search, sorting, or other filters.
- **Surprise Me** — Pick one to three unique tags at random. Preferred tags receive higher odds, while excluded tags remain possible at reduced odds and are never included and excluded simultaneously.
- **Tag-aware summaries** — Saved Filter summaries use tag names, preference states, and configured core tag colors.
- **Lifecycle-safe navigation** — Controls follow Latest route changes and are removed when the add-on is disabled or inactive.

The add-on runs only on the F95Zone Latest Updates page. Preset data remains
local to your browser. Surprise Me uses the tag catalog already provided by the
core and performs no network request or preset write.

Original idea and inspiration from [F95 Latest Update Saver](https://greasyfork.org/en/scripts/523141-f95-latest-update-saver) by **Edexal**. This version is deeply integrated implementation built specifically for the F95UE ecosystem.

The reset-control behavior was adapted from Edexal's [Reset Filters](https://sleazyfork.org/en/scripts/588436-reset-filters) userscript.
