### Requires F95Zone Ultimate Enhancer (core)

Install and enable the [F95Zone Ultimate Enhancer core script](https://greasyfork.org/scripts/546518-f95zone-ultimate-enhancer) first. Thread Utility is a core-managed add-on and will not run without it.

### F95UE Thread Utility Add-on

**A compact dashboard for the important information and tools in an F95Zone thread.**

Open Thread Utility from its thread-page dock button to view the title, version, developer, rating, prefixes, prioritized tags, description, installation notes, and grouped download links without repeatedly navigating the opening post.

### Features

- **Compact Thread Snapshot** — Collect the important opening-post metadata into one bounded dashboard.
- **Prioritized Tags** — Show your preferred, excluded, and marked core tags first, with the remaining tags available on demand.
- **Collapsible Content** — Expand the description, installation information, and download groups independently.
- **Download Actions** — Open the original host link or trigger the matching page-owned Direct DL/Resolve control when available.
- **Quick Searches** — Run configurable thread or forum searches using the current thread title.
- **Thread Utilities** — Copy the thread title or URL and use compact opening-post actions from one place.
- **Configurable Launcher** — Enable or disable the dock launcher and customize visible tags, preview length, search scope, and quick utilities.
- **Lifecycle-safe UI** — Uses core-owned dialogs, mounts, styles, storage, and route cleanup.

The quick-search concept and six initial search presets are adapted from **F95 Utility Buttons** by GGD40727 under its MIT license. Thread Utility does not copy that script's storage or fixed-position page UI.

Thread Utility reads the current thread page only. Its settings remain local to your browser, and it performs no independent download-resolution network requests.
